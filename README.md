# Сугроб ❄︎

Новогодняя погода для macOS: снег идёт поверх экрана, копится на окнах и Dock, ссыпается, когда окна двигают, а раз в несколько минут по Dock проезжает Дед Мороз с подарком.

macOS 14 или новее, Apple silicon и Intel.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/borsschec-gif/sugrob/main/install.sh | bash
```

Приложение живёт в строке меню (❄︎) и обновляется само. Для снега на Dock нужен «Универсальный доступ», для точных углов окон — «Запись экрана» (снимается только угол окна, снимок сразу выбрасывается). Без них снег всё равно работает.

## Что можно делать

- Медленно вести курсор по снегу: скатается снежок.
- Вести быстрее: снег стряхнётся.
- Тащить окно: снег посыплется на окна ниже.
- Кликнуть по подарку от Деда Мороза.
- Смотреть на рабочий стол: снег лежит на папках, а на файлах его нет.
